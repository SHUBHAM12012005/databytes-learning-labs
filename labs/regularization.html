03 / Compare the methods

Choose a tab to review the objective, typical behavior, and when to use each regularizer.

Ridge regression

minimize: (1 / 2n) ||y − Xβ||²₂ + α ||β||²₂
  • Penalizes the sum of squared coefficients.
  • Typically shrinks coefficients toward zero but does not set them exactly to zero.
  • Often useful when many predictors have small or distributed effects, especially with correlated features.
  • Can improve stability when predictors are strongly correlated.

Lasso regression

minimize: (1 / 2n) ||y − Xβ||²₂ + α ||β||₁
  • Penalizes the sum of absolute coefficient values.
  • Can set some coefficients exactly to zero, creating a sparse model.
  • Useful when a smaller set of predictors may explain the signal.
  • With strongly correlated predictors, it may select one and discard others; selection can be unstable across samples.

Elastic Net

minimize: (1 / 2n) ||y − Xβ||²₂ + α·r ||β||₁ + (α·(1 − r) / 2) ||β||²₂
  • Combines L1 sparsity and L2 shrinkage.
  • In this lesson's convention, r is the L1 ratio: 0 is Ridge-like; 1 is Lasso-like.
  • Often helpful with many correlated predictors when some sparsity is desired.
  • Both α and the L1 ratio should be tuned using validation or cross-validation.

Libraries may use slightly different scaling conventions for the loss and penalty; always check the estimator's documented objective.

Feature scaling and penalty strength

Penalties act on coefficient magnitudes, so units matter. Standardize predictors using training data only, then apply the same transformation to validation/test data. Keep the intercept unpenalized in typical implementations.

  • α = 0: no regularization.
  • Small α: mild shrinkage.
  • Large α: stronger shrinkage; too much can cause underfitting.
  • Choose α with a validation set or cross-validation, not by repeatedly checking the final test set.

06 / Regularization interview guide

Common interview questions with concise, technically accurate answers.

Interview prep
1. What is regularization?
Regularization adds a penalty to the training objective to discourage overly complex parameter values. It can improve generalization by reducing variance, though excessive regularization can cause underfitting.
2. Explain Ridge regression.
Ridge adds an L2 penalty, proportional to the sum of squared coefficients. It shrinks coefficients smoothly and is often effective when predictors are correlated. It generally does not produce exact zeros.
3. Explain Lasso regression.
Lasso adds an L1 penalty, proportional to the sum of absolute coefficients. Its geometry and optimization can yield exact zero coefficients, so it can perform feature selection as well as shrinkage.
4. Explain Elastic Net.
Elastic Net combines L1 and L2 penalties. It can create sparse solutions while providing some of Ridge's stabilizing behavior, making it useful when predictors are correlated and sparsity is desired.
5. Ridge vs Lasso?
Ridge usually keeps all predictors with smaller coefficients; Lasso can eliminate predictors by setting coefficients to zero. Ridge often distributes weights among correlated features, while Lasso may choose one of them.
6. What does α control?
α controls overall penalty strength. At zero, the penalty disappears. Increasing α generally increases shrinkage; an excessively large value can make the model underfit. Select α with validation or cross-validation.
7. What is the Elastic Net L1 ratio?
It controls the relative contribution of L1 and L2 penalties. In this lab's convention, 0 is Ridge-like and 1 is Lasso-like. The ratio and α are usually tuned jointly.
8. Why standardize features?
Without scaling, a coefficient's magnitude depends on the units of its predictor. Standardization makes the penalty more comparable across features. Fit the scaler on training data only to prevent leakage.
9. Is regularization always beneficial?
No. It trades variance for bias. It may improve held-out performance when the unregularized model is too sensitive, but too much penalty can remove meaningful signal and underfit.
10. Does Lasso always identify the true features?
No. Selection depends on sample size, noise, correlations, scaling, and model assumptions. With correlated predictors, selected features can vary between samples; stability and domain knowledge matter.
11. How do you choose between Ridge, Lasso, and Elastic Net?
Use Ridge when many predictors may contribute and stable shrinkage is desired; Lasso when sparse selection is useful; Elastic Net when sparsity is desired alongside correlated predictors. Compare with cross-validation using the target metric.
12. Is Ridge a feature-selection method?
Usually not in the strict sense, because Ridge coefficients are generally not exactly zero. It is primarily a shrinkage method. Lasso is more directly associated with sparse feature selection.
13. Does regularization change the intercept?
Common implementations exclude the intercept from the penalty. The intercept is still estimated, but it is not directly shrunk by the regularization term.
14. What is the difference between regularization and cross-validation?
Regularization modifies the objective being optimized. Cross-validation is an evaluation procedure used to estimate out-of-sample performance and tune choices such as penalty strength.
15. Give a concise interview answer.
“Ridge, Lasso, and Elastic Net reduce overfitting by penalizing coefficients. Ridge uses L2 and smoothly shrinks weights; Lasso uses L1 and can set weights to zero; Elastic Net combines both and can be useful with correlated features. I standardize predictors, tune the penalty with cross-validation, and keep the test set for final evaluation.”

Interview checklist

  • Write the L1, L2, and Elastic Net objectives.
  • Explain shrinkage versus sparsity.
  • Know how α and L1 ratio affect the model.
  • Explain why scaling and leakage prevention matter.
  • Discuss correlated predictors and feature-selection stability.
  • Explain cross-validation and the bias–variance trade-off.
